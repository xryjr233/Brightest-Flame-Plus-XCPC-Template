# Brightest Flame+'s Standard Library

模板来自 [Plenty of Penalty's Standard Library](https://github.com/plenty-of-penalty/acm-template.typ)。

运行 ```npm install``` 下载依赖包，不想下的话可以用 ```build_without_reformat.js``` 替代 ```build.js``` 。

运行 ```make.bat``` 来构建 pdf。
